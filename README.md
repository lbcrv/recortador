# Recortador

Quita fondos de fotos desde el navegador del celular. Todo el procesamiento ocurre en el dispositivo: las fotos nunca se suben a ningún servidor (solo se descarga una vez el modelo de IA RMBG-1.4, de uso no comercial).

- **Fondo liso**: detecta y quita un fondo de un solo color al instante.
- **IA**: para fondos complejos (modelo corriendo en el teléfono).
- **Pincel**: borrar / restaurar a mano.
- **Guardar**: PNG transparente o con color de fondo.
